# 2026-10-01 雛形プロンプトの写真表示方法

## 決めたこと
写真の HTML を雛形プロンプトにコードで直接指定する。
`.photo-frame` の中に案内文と `<img src="photo1.jpg" onerror="this.style.display='none'">` を重ねて置く。

## なぜ
「写真がない時は文字で表示して」と言葉で頼むだけだと、Gemini は Canvas のプレビューを見栄えよくするために `src` を仮画像URLや data: に書き換えることがある。そうなるとダウンロード後に写真を入れても表示されず、初心者は原因に気づけない。
onerror なら `src="photo1.jpg"` が残ったまま、写真がない時（Canvas）は案内文、ある時（ローカル・Netlify）は写真に自動で切り替わる。
透過PNGだと案内文が透けて見えたため、img に背景色をつける指定も入れた。

## 却下した選択肢
- 案内文を img の次の要素に置いて nextElementSibling で表示を切り替える：Gemini が要素の並びを変えると壊れる
- JavaScript で画像の有無を判定する：コードが長くなり、Gemini が書き換える余地も増える
